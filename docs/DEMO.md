# Demo and screenshots

A public hosted demo is intentionally not published yet because the dashboard controls real GitHub installations and requires administrator authentication.

To capture trustworthy screenshots:

1. Run EliteGitBot locally with a development GitHub App and sanitized test repository.
2. Populate D1 through signed test webhooks rather than hardcoded production fixtures.
3. Capture the overview, repository settings, PR findings, issue triage, and mobile navigation.
4. Remove account names, private repository names, commit SHAs, and URLs before publishing.

Screenshots and an animated workflow demo should be added only after a sanitized environment is available. This prevents the README from presenting mock statistics as production behavior.
